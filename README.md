# 🍏 Agro Tech One

## Descrição

O **Agro Tech One** é um sistema para propriedades rurais, com foco na fruticultura. Ele permite gerenciar controles de atividades agrícolas e financeiros, auxiliando produtores rurais na tomada de decisão.

---

## Funcionalidades

- ✅ Gerenciamento de atividades agrícolas  
- ✅ Controle financeiro  
- ✅ Relatórios completos  
- ✅ **Geração de arquivos (PDF, planilhas) para exportação de dados**  
- ✅ Interface intuitiva e fácil de usar  

---

## Tecnologias Utilizadas

- **Java Web** (Servlet, JSP)
- **PostgreSQL 17**
- **JavaScript**
- **Bootstrap 4**

---

## Como Instalar e Rodar

### Modo 1: Hospedagem Online

1. Hospede a aplicação em um servidor web compatível com Java e PostgreSQL.
2. Acesse via navegador com conexão à internet.

### Modo 2: Rede Local

1. Instale Java JDK 8+ e PostgreSQL 17 em seu servidor local.
2. Instale um servidor de aplicação (ex: Tomcat).
3. Importe o banco de dados e configure o acesso.
4. Acesse a aplicação pela rede interna.

> **Pré-requisitos:**
> - Java JDK 8 ou superior  
> - PostgreSQL 17  
> - Tomcat ou similar  
> - Navegador web  

---

## 📁 Geração de Arquivos

O sistema permite gerar relatórios em PDF ou planilhas (Excel) com informações detalhadas das atividades e finanças.  
Acesse o menu “Relatórios” e clique em “Gerar Arquivo” para exportar os dados desejados.
